Key Design Question: How does data flow from group to sink?

What type does the GroupData output carry?

A

Dictionary<string, object>

Each group component outputs a dictionary of column-name/value pairs. The Send component merges them. Simplest — matches the existing CollectValues pattern directly.

B

Custom GH_Goo<T> type

A "FieldGroup" Goo type that carries typed fields + group metadata. Stronger typing, better canvas display (shows group name in tooltips), but more SDK boilerplate.

C

JSON string

Each group serializes to JSON. Send component parses and merges. Simplest wire type (just text), but loses type safety and makes debugging harder.
