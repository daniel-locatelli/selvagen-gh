A: Right-Click Group Toggles

Right-click the component to show a menu with checkable groups. Toggle a group to add/remove its input pegs. Starts empty — user enables what they need.

Pros

  • Most GH-idiomatic
  • Low implementation effort
  • No new UI framework

Cons

  • Bulk toggling is tedious
  • Hidden behind right-click
  • No visual grouping on canvas

B: "Configure Fields" Dialog (Recommended)

Right-click → "Configure Fields..." opens a dialog with grouped checkboxes, search, and "Select All" per group. Apply rebuilds the input pegs. Cross-platform via Eto.Forms.

Pros

  • Best discoverability
  • Bulk operations easy
  • Scales to 30+ fields
  • Can include presets

Cons

  • Medium implementation effort
  • Modal dialog breaks reactive flow slightly

C: Small Composable Components

Break each module into group-level components (Topo Base, Topo Slope, etc.) with 3-6 inputs each. Wire only the groups you need into a final "Upload" sink component.

Pros

  • Each component tiny & clear
  • Canvas reads like a data flow
  • Eliminates cross-component duplication
  • Most extensible

Cons

  • High effort (~25 new classes)
  • Canvas can balloon
  • Breaks existing definitions
  • New aggregation logic needed
